# Rust Skills Refresher Challenges

This collection of challenges is designed to help you refresh your Rust skills based on the concepts you've previously learned. Each challenge builds on fundamental concepts and gradually increases in complexity.

## Challenge Categories

### 🏗️ **Fundamentals Review** (Challenges 1-3)
- Basic syntax, ownership, and borrowing
- Error handling patterns
- Structs and enums

### 🧠 **Intermediate Concepts** (Challenges 4-6)
- Generics and traits
- Collections and iterators
- Module organization

### 🚀 **Advanced Applications** (Challenges 7-9)
- Concurrent programming
- Network programming
- JSON handling and APIs

## How to Use These Challenges

1. **Start with the fundamentals** - Even if they seem basic, they'll help refresh core concepts
2. **Build incrementally** - Each challenge introduces or reinforces multiple concepts
3. **Focus on understanding** - Don't just make it compile, understand why it works
4. **Experiment** - Modify the challenges to explore edge cases

## Getting Started

Each challenge is in its own directory with:
- A `README.md` explaining the challenge
- Starter code (if applicable)
- Hints for when you're stuck
- A solution (try not to peek too early!)

Start with `challenge_01_inventory_manager` and work your way through!

## Quick Rust Refresher Commands

```bash
# Create a new project
cargo new project_name

# Run a project
cargo run

# Check for compilation errors without building
cargo check

# Run tests
cargo test

# Build optimized release version
cargo build --release
```

Happy coding! 🦀
